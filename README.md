# CONV-WAY

### Ambient Multi-Modal Intelligence for Non-Linear, Interactive YouTube Playback

***"Don't pause your curiosity, let the video follow it."***

---

## 00 // Product Manifesto & Real-World Problem

Whether a student is watching a two-hour technical podcast, or a **farmer, kirana store owner, or rural health worker** is learning from long-form instructional YouTube video in an Indian language, passive video playback forces a painful trade-off:

1. Pause the video manually when a complex claim or unfamiliar term comes up.
2. Open a new browser tab and formulate a search query.
3. Sift through unverified text results.
4. Scrub back and forth trying to find the original timestamp and context.

**Conv-way** eliminates context-switching friction. It is a **zero-sign-in responsive web companion** that lets viewers talk directly to any YouTube video while it plays. Ask a question out loud (via **Push-to-Talk** or hands-free **Ambient Voice Mode**), type a query, or tap a pre-computed question in the quiet **Way** side panel: Conv-way saves your exact millisecond playhead in a **Last-In, First-Out (LIFO) Call Stack**, jumps directly to the authoritative answering video segment (in-video or via an external YouTube Picture-in-Picture clip), and returns you seamlessly to where you left off.

## 01 // Core Capabilities & Engineering Highlights

### `[01]` Messy Audio Isolation, WebRTC Noise Cleanup & Dynamic Ducking
Real-world users rarely wear studio headphones. To handle noisy rooms and loudspeaker echo:
* **AudioWorklet & VAD:** Custom real-time worklet filters room noise and isolates human voice frequencies ($85\text{ Hz}\text{--}3000\text{ Hz}$) using WebRTC constraints (`echoCancellation: true`, `noiseSuppression: true`, `autoGainControl: true`).
* **Dynamic Audio Ducking / Auto-Pause:** Automatically attenuates primary video volume to `18%–20%` on headphone setups—or auto-pauses playback on open mobile/laptop speakers—the instant speech is detected.

### `[02]` Four Frictionless Ways to Ask
* **Push-to-Talk (`HOLD TO SPEAK`):** Reliable baseline across all desktop and mobile browsers.
* **Ambient Voice Mode:** Opt-in continuous listening triggered by local Voice Activity Detection (VAD).
* **Text Query Bar:** Always-available keyboard fallback.
* **The "Way" Side Panel:** One-tap questions predicted ahead of the playhead.

### `[03]` Frugal "Way" 4-Minute Window Indexing (Zero Wasted Compute)
Instead of burning AI tokens and database writes by indexing an entire 2-hour video on page load:
* **2.0-Second Watch Confirmation Gate:** Transcript ingestion (`POST /api/videos/:videoId/init`) is blocked until the viewer has actively watched the video for $\ge 2.0\text{ seconds}$ of continuous playback.
* **600–800 Word Speech Windows:** Captions are chunked into ~4-minute windows (~30 rows per 2-hour podcast instead of 3,600+ individual caption lines), cutting Cloudflare D1 write operations by $>99\%$.
* **Shared Edge Cache:** Predicted questions generated by **Gnani Evon v3.3** are cached in **Cloudflare D1** by `(video_id, window_index, language)` so one viewer's compute serves every subsequent viewer for free.

### `[04]` LIFO Playhead Call Stack & Multi-Hop Detours
Traditional video players operate on a flat linear timeline (`00:00 -> Duration`). Conv-way manages playback state as a **Last-In, First-Out (LIFO) Stack** in memory:

$$\text{Call Stack} = [T_{\text{origin}}, T_{\text{branch\_1}}, \dots, T_{\text{branch\_n}}]$$

* Every detour pushes `{ videoId, returnTimestamp, playbackRate, volume, branchId }` onto the stack.
* Viewers can chain nested follow-ups (*"Dive Deeper"*) and pop back one level (`← BACK 1 LEVEL`) or jump straight to their root timestamp (`↺ ORIGIN [MM:SS]`).

### `[05]` Multi-Modal Gnani AI Integration + 3,000-Credit Governor
* **Gnani Prisma v3.0 (Speech-to-Text):** Hybrid voice router uses free browser `SpeechRecognition` when supported and seamlessly routes noisy audio streams, unsupported browsers, and 9 Indian languages (`hi`, `bn`, `mr`, `gu`, `pa`, `kn`, `te`, `ta`, `ml`) to **Prisma v3.0**.
* **Gnani Evon v3.3 (30B MoE LLM):** Powers **Way** question generation, BM25 candidate reranking, exact clip boundary extraction, and 30–40 word verified web fallback synthesis.
* **Gnani Timbre (Text-to-Speech):** Provides opt-in spoken readout for synthesized fallback answers.
* **Daily Credit Governor:** Dynamically enforces $\text{Daily Cap} = \frac{\text{Remaining Pool}}{\text{Days Left}} \times 0.90$ ($\approx 73\text{ credits/day}$), stepping down gracefully to cached **Way** windows + SQLite FTS5 + browser STT if daily limits are reached—guaranteeing $100\%$ playback uptime at $\$0$ cost.

## 02 // System Architecture & Tech Stack

| Layer | Technology | Role in Production |
| :--- | :--- | :--- |
| **Frontend Runtime** | React 18, TypeScript, Vite, Tailwind CSS, Zustand 5 | Pre-app architectural gallery, dual YouTube IFrame orchestrator, and LIFO call stack state. |
| **Audio & Voice** | Web Audio API, AudioWorklet, WebRTC AEC, Silero/RMS VAD | Real-time acoustic echo cancellation, noise cleanup worklet, and 18% dynamic audio ducking. |
| **Speech-to-Text** | Browser `Web Speech API` $\rightarrow$ **Gnani Prisma v3.0** | Zero-credit native STT primary path with automatic fallback to Gnani Prisma for noisy/multilingual Indian speech. |
| **LLM & TTS** | **Gnani Evon v3.3 (30B MoE)** + **Gnani Timbre** | Window question generation, timestamp boundary alignment, and citation-backed fallback synthesis. |
| **Edge Backend** | Cloudflare Pages + Cloudflare Workers (Hono + Zod) | 0ms cold-start API routing, strict schema validation, rate limiting, and secret isolation. |
| **Database & Search** | Cloudflare D1 (SQLite + `FTS5` BM25) + Workers KV | Windowed transcript storage, Porter-stemmed `FTS5` full-text search, and shared **Way** question cache. |
| **Captions & Citations**| Supadata API (Primary) $\rightarrow$ TranscriptAPI (Fallback), YouTube Data API v3, Google CSE | Swappable caption ingestion behind an adapter + verified web search URLs for AI fallback cards. |

## 03 // Local Setup & Development

### 1. Prerequisites
* **Node.js:** `v20.11.0+`
* **Cloudflare Wrangler CLI:** `npm install -g wrangler`

### 2. Install Dependencies
```bash
git clone https://github.com/chauhanaman41/conv-way.git
cd conv-way
npm install
```

### 3. Configure Environment Variables
Copy `.env.example` to `.dev.vars` (used by Cloudflare Wrangler for local Worker secrets) and configure your keys:
```bash
cp .env.example .dev.vars
```

Required keys in `.dev.vars`:
* `YOUTUBE_DATA_API_KEY` — Google Cloud YouTube Data API v3 key
* `SUPADATA_API_KEY` — Primary transcript ingestion key
* `TRANSCRIPT_API_FALLBACK_KEY` — Secondary transcript fallback key
* `GNANI_API_KEY` / `GNANI_ACCESS_TOKEN` — Gnani AI credentials (Prisma v3.0, Evon v3.3, Timbre)
* `WEB_SEARCH_API_KEY` / `WEB_SEARCH_CX` — Verified web citation lookup keys

### 4. Initialize Local Database & Migrations
```bash
npx wrangler d1 migrations apply conv-way-db --local
```

### 5. Start Full-Stack Server
```bash
npm run dev
```

Open `http://localhost:3000` to view the application.

## 05 // Public Deployment (Cloudflare Free Stack — $0/Month)

1. Authenticate Wrangler:
   ```bash
   npx wrangler login
   ```
2. Create your remote D1 database and apply migrations:
   ```bash
   npx wrangler d1 create conv-way-db
   npx wrangler d1 migrations apply conv-way-db --remote
   ```
3. Store production secrets:
   ```bash
   npx wrangler secret put YOUTUBE_DATA_API_KEY
   npx wrangler secret put SUPADATA_API_KEY
   npx wrangler secret put GNANI_API_KEY
   ```
4. Build and deploy:
   ```bash
   npm run build
   npx wrangler pages deploy dist --project-name conv-way
   ```
